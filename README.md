# human-activity-recognition
Human Activity Recognition using Smartphone Sensor Data and Machine Learning.

Machine Learning project developed as part of the Pattern Recognition course at the University of Peloponnese.

## Algorithms
- Support Vector Machine (SVM)
- Logistic Regression
- Random Forest
- Multilayer Perceptron (MLP)
- k-Nearest Neighbors (kNN)
- Naive Bayes

## Dataset
UCI Human Activity Recognition Using Smartphones Dataset.

## Results
Best accuracy achieved: 95.69% using SVM.

## Technologies
Python, Scikit-learn, NumPy, Pandas, Matplotlib.
